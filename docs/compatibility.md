## 🧩 兼容性说明   
理论上支持所有通过 XInput 控制手柄震动的游戏，实际兼容性因游戏而异，待验证。  
**必须使用支持 XInput 的手柄并禁用Steam输入**

### 已验证兼容游戏

| 游戏 | 进程名 | 适配程度 | 测试插件版本 | 备注 |       
| :--- | :--- | :--- | :--- | :--- |     
| 星际拓荒 | `OuterWilds.exe`  | 完美 | 1.6.0/1.7.5 | 无  |     
| 死亡搁浅 导剪版 | `ds.exe` | 一般 |  1.6.0| DGHUB后台运行时插件可能被杀后台 |     
| 怪物猎人：崛起 |`MonsterHunterRise.exe` | 完美 | 1.6.0 |  无 |    
| 冰与火之舞 | `略` | 不支持 | 1.6.0 | 游戏不向手柄发送震动信息 |   
| 史莱姆牧场2 | `SlimeRancher2.exe` | 完美 | 1.7.5 | 1.7.5版本后可兼容 |  
| 空洞骑士 | `hollow_knight.exe` | 完美 | 1.7.5 | 需在游戏手柄设置里开启震动和XINPUT |
