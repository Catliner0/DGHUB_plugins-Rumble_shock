理论上支持所有通过 XInput 控制手柄震动的游戏，实际兼容性因游戏实现而异，需自行验证。  
**必须使用支持 XInput 的手柄，并关闭 Steam Input。**

### 已验证兼容游戏

| 游戏 | 进程名 | 适配程度 | 备注 |       
| :--- | :--- | :--- | :--- |  
| 星际拓荒 (Outer Wilds) | `OuterWilds.exe` | 完美 | 无  |     
| 死亡搁浅 导演剪辑版 | `ds.exe` | 一般 |  DGHUB后台运行时插件可能被杀后台 |     
| 怪物猎人：崛起 |`MonsterHunterRise.exe` | 完美 | 无 |    
| 冰与火之舞 | `略` | 不支持 | 游戏不向手柄发送震动信息 |
