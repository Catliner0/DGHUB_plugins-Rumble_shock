## 📖  插件简介  

本插件会挂钩游戏进程中的 `XInputSetState`和`HID DeviceIoControl`，实时获取左右马达震动强度，并按你配置的规则映射为电击强度与波形，通过 DGHub 发送给已连接的 DG-Lab 设备

## 🚀 快速部署  
**1. 下载与解压**  
本项目采用分卷压缩上传，请下载以下文件并放在同一文件夹：

- `手柄震动映射.7z.001`
- `手柄震动映射.7z.002`
- `手柄震动映射.7z.003`

使用 7-Zip、Bandizip、WinRAR 等解压即可。若解压遇到问题，可使用附带的解压程序 `手柄震动映射.exe` 辅助解压  

**2. 导入插件**  
解压后找到 `main.zip`（插件本体），打开 **DGHub → 插件中心 → 外部插件 → 导入该 zip**  

**3.配置插件**  
在**DGHUB** →**插件中心** →**外部插件**中找到本插件，在插件配置页填写要监听的**游戏进程名**   
`插件运行时无法修改配置 请先停止再调整`

**4.开始使用**    
启动插件并开始游戏   
**确认游戏使用XInput手柄输入并禁用 Steam 输入**

<h2 id="compatibility"></h2>  

## 🧩 兼容性说明   
理论上支持所有通过 XInput 控制手柄震动的游戏，实际兼容性因游戏而异，待验证。  
**必须使用支持 XInput 的手柄并禁用Steam输入**

### 已验证兼容游戏

| 游戏 | 进程名 | 适配程度 | 测试插件版本 | 备注 |       
| :--- | :--- | :--- | :--- | :--- |     
| 星际拓荒 (Outer Wilds) | `OuterWilds.exe`  | 完美 | 1.6.0 | 无  |     
| 死亡搁浅 导演剪辑版 | `ds.exe` | 一般 |  1.6.0| DGHUB后台运行时插件可能被杀后台 |     
| 怪物猎人：崛起 |`MonsterHunterRise.exe` | 完美 | 1.6.0 |  无 |    
| 冰与火之舞 | `略` | 不支持 | 1.6.0 | 游戏不向手柄发送震动信息 |   
| 史莱姆牧场2 | `SlimeRancher2.exe` | 完美 | 1.7.2 | 1.7.2版本后可兼容 |
